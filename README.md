# Mouge Website

This folder contains the verified responsive Mouge website.

## Deployment

- Entry file: `index.html`
- Static site: no build step required
- Works on iPhone, Android, tablet, and desktop layouts
- Keep this folder in version control and retain the `backups/` copy before making future edits

## Important

The waitlist form uses FormSubmit and must be activated from the destination email address on the live domain.
